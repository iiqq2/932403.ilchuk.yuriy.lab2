## Вариант 17: языковое оформление

Наведите указатель на кнопку **RU** или **EN**, перейдите на неё клавишей Tab либо нажмите её на сенсорном устройстве. Одновременно меняются язык страницы и оформление. Выбранный язык сохраняется до выбора другой кнопки или перезагрузки страницы.

`script.js` получает значения из CSS-переменных кнопки через `getComputedStyle()` и меняет переменные корневого элемента через `setProperty()`. Цвета и шрифты не заданы в JavaScript: они описаны в `style.css`.

- **RU:** яркий бирюзовый `#22d3ee`, заголовки Arial, рамка полей с белым, синим и красным цветами.
- **EN:** светлый бирюзовый `#67e8f9`, заголовки Georgia, рамка полей с белым и красным цветами английского флага.
- Основной цвет задан переменной `--primary`, белый акцент — `--accent`.
- При фокусе поля получают градиентную рамку через `--focus-border`.

При выборе **RU** все тексты отображаются на русском, при выборе **EN** — на английском. Переводятся заголовки, навыки, проекты, описание EngCLI, подписи и подсказки формы, заголовок вкладки и атрибуты доступности. Также обновляется `lang` HTML-документа. Введённые значения полей сохраняются при переключении. Русские тексты берутся из HTML, английские — из словаря в `script.js`. Информация об изучаемом языке остаётся прежней: английский.

## Файлы

- `index.html` — семантическая разметка, inline-стиль и внутреннее CSS-правило.
- `style.css` — основное оформление, палитры и состояния элементов.
- `script.js` — перевод страницы и переключение CSS-переменных.
- `images/avatar.svg` — иллюстрированный аватар.

Форма представляет HTML-разметку без серверного обработчика. Подвал остаётся удалённым по ранее принятому решению для страницы из лабораторной №1.
